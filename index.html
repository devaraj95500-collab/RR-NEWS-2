PNG కార్డులో హెడ్‌లైన్, వార్త వివరాలు, RR NEWS బ్రాండింగ్ ఉంటాయి. అప్లోడ్ చేసిన ఫోటోను ఈ సాధారణ కార్డు ఎగుమతిలో చేర్చడం లేదు.

🎬 AI యాంకర్ వీడియో స్టూడియో

30–60 సెకన్ల షార్ట్ న్యూస్ లేదా 1–3 నిమిషాల బులెటిన్ కోసం వీడియో అభ్యర్థనను సిద్ధం చేయండి.

పారదర్శక గమనిక: ఈ ప్రాజెక్ట్‌లో నిజమైన AI వీడియో ప్రొవైడర్ ఇంకా కనెక్ట్ కాలేదు. URL ఖాళీగా ఉంటే అభ్యర్థన పంపబడదు. పని చేసే వీడియో కోసం బ్యాక్‌ఎండ్ సర్వర్ మరియు AI సేవ API credentials అవసరం. API secret keyని ఈ యాప్‌లో లేదా పబ్లిక్ GitHub రిపాజిటరీలో పెట్టవద్దు.
